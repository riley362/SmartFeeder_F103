#### 1. 核心控制与视觉通信

| **模块名称**    | **模块引脚**  | **接 STM32 或 电源** | **备注说明 (走线建议)**       |
| --------------- | ------------- | -------------------- | ----------------------------- |
| **STM32F103**   | 5V / VIN      | 接 **5V 电源轨**     | 核心板供电输入                |
|                 | GND           | 接 **系统公共 GND**  | 共地                          |
| **K210 视觉板** | VCC           | 接 **5V 电源轨**     | K210 功耗不小，建议用 5V 供电 |
|                 | GND           | 接 **系统公共 GND**  | 必须共地                      |
|                 | **IO_8 (TX)** | **PA10 (RX)**        | 串口交叉连接                  |
|                 | **IO_6 (RX)** | **PA9 (TX)**         | 串口交叉连接                  |

#### 2. 云端通信 (ESP8266)

| **模块名称** | **模块引脚** | **接 STM32 或 电源**    | **备注说明**              |
| ------------ | ------------ | ----------------------- | ------------------------- |
| **ESP8266**  | VCC          | 接 **独立 3.3V 电源轨** | **绝对不能接 5V，会烧！** |
|              | GND          | 接 **系统公共 GND**     |                           |
|              | EN / CH_PD   | 接 **独立 3.3V 电源轨** | 必须拉高，否则模块不工作  |
|              | TXD          | **PA3 (RX)**            | 串口2交叉连接             |
|              | RXD          | **PA2 (TX)**            | 串口2交叉连接             |

#### 3. 传感器阵列 (环境与状态感知)

| **模块名称**      | **模块引脚**  | **接 STM32 或 电源**    | **备注说明**                                                 |
| ----------------- | ------------- | ----------------------- | ------------------------------------------------------------ |
| **BH1750 (光照)** | VCC           | 接 **独立 3.3V 电源轨** | IIC 逻辑电平推荐 3.3V                                        |
|                   | GND           | 接 **系统公共 GND**     |                                                              |

|                   | A0 (模拟输出) | **PA0 (ADC1_IN0)**      | ⚠️ *注意：尽量不要让测试气体浓度过高，防止输出电压超过 3.3V 烧坏 PA0 引脚* |
| **水位红外对管**  | VCC           | 接 **独立 3.3V 电源轨** |                                                              |
|                   | GND           | 接 **系统公共 GND**     |                                                              |
|                   | OUT (输出)    | **PB0**                 | GPIO 输入                                                    |

|                   | GND           | 接 **系统公共 GND**     |                                                              |
|                   | OUT (输出)    | **PB1**                 | GPIO 输入                                                    |
